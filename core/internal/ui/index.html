定时与探测
DNS 与切换策略

支持 UDP（字面 IP）、DoT（tls://主机[:853]）、DoH（https://主机/路径），可混用；DoQ 暂不支持。

DNS 应答器（供 AdGuard Home 上游分流）

留空使用默认值 127.0.0.1:18053 与 60 秒。地址必须是 IP 字面量（留空 host 表示监听全部接口，需自行加防火墙）；填 off / disabled / none / 0 / false 可禁用。修改后下一轮探测会自动重绑监听，页面「DNS 应答服务」卡片会显示当前值与分流规则。AdGuard Home 用 Docker 部署时，这里填 0.0.0.0:18053 或 NAS 内网 IP；填 0.0.0.0 时分流行会自动替换为本机内网 IP。

注意：与 AdGuard Home 的过滤器订阅二选一，不要同时启用。

产物与校验

HTTP 状态码白名单默认不校验：多数站点根路径返回 403/404，开启后可能误杀可用 IP；outputs 为保留字段，三项产物当前固定生成。

使用说明

  
    
    
  1. 在「编辑域名清单」中添加域名，或输入主域名后勾选相关子域名批量添加，最后点「保存并生效」。
    2. 
    
  2. 推荐：展开「DNS 应答服务」卡片，复制分流规则，粘贴到 AdGuard Home「设置 → DNS 设置 → 上游 DNS 服务器」末尾。IP 切换后最多一个 TTL 即生效。
    3. 
    
  3. 兼容：也可在 AdGuard Home「过滤器 → DNS 重写清单」添加订阅地址 http://<NAS内网IP>:18088/agh.txt，更新间隔设为 1 小时。与上一种方式二选一，不要同时启用。
    4. 
    
  4. 需要立即更新时，展开域名分组后勾选并点「刷新选中」；只想重写订阅文件时点「刷新 AGH 规则」。
    5. 
    
  5. 点击延迟数值可查看全部候选 IP 并手动切换；状态表支持按主域名分组以及启用/禁用域名。
    6. 
    
  6. 所有配置项（轮询、探测 DNS、滞回、子域名展开、DNS 应答器、产物与校验）都在「编辑域名清单」的图形化表单内，单域名的高级项点该行「高级」展开；需要时也可切到「JSON 源码」。
    7. 
    
  7. 其他端点：/hosts.txt（hosts 语法）、/status.json（运行状态与统计）、/api/dns（应答器状态与分流规则）。
    8. 
  




管理接口与 DNS 应答器均无登录鉴权，请仅在内网使用；DNS 应答器默认只监听本机回环地址，如需对外监听请自行添加防火墙规则。刷新任务状态保存在进程内存，重启后重新触发即可。
