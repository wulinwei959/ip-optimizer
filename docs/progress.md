## 已知限制

- 管理接口需令牌（`X-Admin-Token` / Bearer / `?token=`），令牌在共享目录 `admin-token`；仍只应部署在内网。
- 刷新任务状态只存进程内存，重启后需重新触发（产物不受影响）。
- 定向刷新不重新展开子域名；手动整轮刷新强制重新展开（绕过 TTL 缓存）。
- DoQ 需要第三方 QUIC 库，按零依赖约束不支持。
- DNS 应答器 TCP 为回退通道，与 UDP 同端口；应答器无鉴权，对外监听需自行加防火墙。
- 新版本检查依赖 `api.github.com`，失败静默；`HO_UPDATE_CHECK=off` 可关。
- IP 抖动与滞回表现仍需长期观察；AdGuard Home 订阅的长期更新效果待持续验证。
